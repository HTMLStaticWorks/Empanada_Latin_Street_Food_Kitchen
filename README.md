# Casa Empanada — Empanada & Latin Street Food Kitchen Website Template

**Casa Empanada** ("Latin Flavor. Street Soul.") is a commercial-grade, multi-page HTML5 website template designed for modern empanada kitchens, Latin street food spots, food halls, catering services, and pop-up counters.

Built with **Bootstrap 5**, **GSAP**, **Vanilla CSS (CSS Variables, Light/Dark theme)**, and **JavaScript**.

---

## 🌟 Key Features

- **12 Complete Pages**: Production-ready, fully responsive HTML files with zero lorem ipsum and zero placeholders.
- **Dual Light / Dark Theme System**: Auto-detects system settings, toggles via navbar icon, and persists user choice in `localStorage`.
- **Mandatory Responsive Navbar**: Features a working dropdown for **Home 1 (Editorial Classic)** & **Home 2 (The Empanada Counter)**, theme switcher, and mobile navigation drawer.
- **Interactive Food Features**: Category tab filtering on `menu.html`, interactive flavor showcase on `home-2.html`, and live order modal.
- **Form Validation & Toasts**: Contact and catering enquiry forms feature HTML5 validation and interactive toast confirmation feedback.
- **SEO & Accessibility**: Semantic HTML5 markup, ARIA accessibility attributes, Google Fonts, and Open Graph metadata.

## 🎨 Color Palette & Customization

Colors are defined using CSS variables at the top of `assets/css/style.css`:

- **Warm Cream Background**: `#FDF8F2`
- **Terracotta Primary**: `#D95D39`
- **Chili Red Accent**: `#C0392B`
- **Golden Yellow**: `#E9A036`
- **Herb Green**: `#3E7B54`
- **Deep Cocoa / Charcoal**: `#2C1D11` / `#1E150F`
