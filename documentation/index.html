1. Template Overview

Casa Empanada is a commercial-grade, multi-page HTML5 template designed for Empanada & Latin Street Food Kitchens. It features a rich design system, custom CSS variable tokens, full Light & Dark theme persistence, responsive Bootstrap 5 grid layout, and interactive GSAP animations.

3. Theme System & Colors

Colors are controlled via CSS variables in assets/css/style.css. You can easily modify the primary terracotta accent, chili red, and warm cream background variables:

:root {
  --bg-primary: #FDF8F2;
  --accent-primary: #D95D39; /* Terracotta */
  --accent-secondary: #C0392B; /* Chili Red */
  --accent-yellow: #E9A036; /* Warm Golden */
  --accent-green: #3E7B54; /* Herb Green */
}

[data-theme="dark"] {
  --bg-primary: #140E0A;
  --accent-primary: #E56E4B;
}

4. HTML Pages

All 12 pages are fully responsive and visually complete with authentic Latin street food copywriting, realistic menus, and active navbar links.
